# Polices des affiches

Depose ici les fichiers `.woff2` de la police du club, nommes
`<Famille>-<graisse>.woff2`.

Exemple :

```
Barlow-400.woff2
Barlow-700.woff2
Barlow-800.woff2
```

Ils sont inlines en base64 dans le document HTML au moment du rendu, donc
l'affiche est identique sur ton Mac et sur le serveur. Sans fichier ici, une
pile de polices systeme generique est utilisee.
